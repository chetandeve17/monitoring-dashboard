# AI Monitoring Dashboard

A real-time monitoring dashboard built using React.js and Node.js.

## Features
- Candidate Monitoring Logs
- Violation Tracking
- Severity Filters
- Search Functionality
- Responsive Dashboard UI
- Backend API Integration

## Tech Stack
- React.js
- Tailwind CSS
- Node.js
- Express.js

## Run Frontend
npm run dev

## Run Backend
node server.js
